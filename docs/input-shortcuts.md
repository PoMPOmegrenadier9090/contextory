# 入力・ショートカット

更新日: 2026-10-20

Web / Desktop共通。MacではCmd、それ以外はCtrlを使う。タブ操作はPC表示のみ。

| キー | 操作 |
| --- | --- |
| Cmd/Ctrl + , | 設定を開く |
| Cmd/Ctrl + K | Entityの検索・Quick Open |
| Cmd/Ctrl + F | Entry本文の右上に検索欄を表示。スクロール位置を保ち、再度押すと検索語を選択 |
| 検索欄でEnter / Shift + Enter | 次の一致・前の一致へ移動 |
| 検索中にEsc | 検索欄を閉じる |
| Quick OpenでCmd/Ctrl + Enter | 検索結果を新規タブで開いて移動 |
| Entityの名前・参照をCmd/Ctrl + クリック | 現在の画面を保ったまま背景のタブで開く |
| Cmd/Ctrl + T | 新規タブ（Home）を開く |
| Cmd/Ctrl + W | 現在のタブを閉じる |
| タブ列で ← / → / Home / End | 開いているタブを選択 |
| Cmd/Ctrl + S | 入力中のプロパティを確定して保存 |
| Cmd/Ctrl + Shift + Enter | Quick Captureを開く |
| Cmd + ← / Home | 箇条書き・番号付きリスト・Todoの本文先頭へ移動 |
| Shift + Cmd + ← / Shift + Home | 箇条書きの本文先頭まで選択 |
| Option/Alt + ← / → | 日本語・英語の単語単位で移動 |
| Shift + Option/Alt + ← / → | 単語単位で選択 |
| ダブルクリック | 単語を選択 |
| Enter | 箇条書き・番号付きリスト・Todoを継続。空の項目では階層を戻すかリストを終了 |
| Tab / Shift + Tab | リスト項目を子階層へ移動・親階層へ戻す。通常の本文では2スペースを追加・解除 |
| Esc | 本文エディタのフォーカスを解除。プロパティ入力では確定して解除（一覧セル・期限入力は取消） |
| Cmd/Ctrl + Z / Shift + Cmd/Ctrl + Z | 本文のUndo / Redo |
| Cmd/Ctrl + B / I / Shift + X | 太字・斜体・取り消し線を切り替える |
| Cmd/Ctrl + クリック | 編集中のMarkdownリンクを開く |
| Cmd + ← / →（入力欄以外） | 画面履歴を戻る・進む |

日本語変換中のEnterではプロパティの確定・フォーカス解除を行わない。
モーダル表示中は画面共通の保存・Quick Captureショートカットを停止する。
単語の区切りには実行環境の`Intl.Segmenter`を使う。

スマホの本文エディタとクイックメモでは、入力中にキーボードのすぐ上へ書式の操作バーを表示する。
操作バーは角丸の形で本文の手前に浮かび、右端のボタンでキーボードを閉じられる。
キーボードの開閉や画面のスクロールに追従し、本文からフォーカスが外れると隠れる。
「B」で太字、「I」で斜体、「S」で取り消し線を切り替え、「←」でインデントを減らし、「→」で増やす。
選択中の文字に適用でき、文字を選択せずに書式を有効にすると、続けて入力する文字に適用する。
有効な書式のボタンは背景色で示す。操作中も選択範囲と本文のフォーカスを保つ。
リストではTab / Shift + Tabと同じ階層変更を行う。読み取り専用の本文には操作バーを表示しない。

`1. `などの番号付きリストは、本文や箇条書きの直後でも空の項目から認識する。
Tabで作る子階層の番号は1から始まり、Shift+Tabで戻すと親階層の続きになる。
既存項目の階層を変えた場合も、そのリスト内の番号を振り直す。
子項目は親の本文位置までインデントしてMarkdownとして保存する。

HTMLを持つコピーは、見出し、強調、リンク、箇条書き、コード、引用、単純な表を
Markdownへ変換する。コード内への貼り付け、通常のテキスト、セル結合を含む表は
元のテキストを貼り付ける。画像・ファイルの貼り付けは既存の添付処理を使う。

WebのEntry表示はLive編集とRawの2種類。Backlinksは初期状態で折り畳み、Webでは
開いたときに取得する。Timelineは本文を高さで省略し、「本文をすべて表示」から詳細を開く。

Homeは通常のタブとして置き換え・閉じる・ドラッグによる並べ替えができる。
最後のタブを閉じると新しいHomeが開く。同じEntityは既存タブを再利用する。
スマホではタブ列・タブ管理・新規タブ操作を表示しない。一覧から詳細へ進み、
戻る操作で一覧へ戻る一画面の構成にする。詳細はメイン画面に表示する。
Homeの階層はアイコン・名前・状態や期限の短い補足でコンパクトに表示する。
Entityページの詳細モードの関連項目と種別ごとのページは表に統一する。Entry以外のEntityページでは「詳細 / Timeline」で関連Entryの本文一覧へ切り替えられ、「直接のみ / 配下も含む」で関連範囲を選択する。
スマホでも表を使い、横スクロールで各プロパティを編集する。一覧表示はHomeに残す。
詳細の星ボタンでそのEntityをピン留めできる。
Project・Taskの進行中は小さな緑ライトで示す。Taskの状態アイコンは未着手が空の円、
進行中が半分塗られた緑の円、保留が一時停止、完了がチェック付きの円となる。
期限欄を押すと日付・時刻と「終日」の選択を表示する。「適用」またはEnterで保存し、
Escや外側のクリックで取消。「解除」で期限を空欄にする。

通常のWebブラウザーではCmd/Ctrl+T・Wがブラウザーに予約されているため、
アプリへキー入力が届かない場合がある。「＋」と各タブの「×」でも同じ操作ができる。
Webのタブ切り替え・閉じる操作でも未保存の確認を行い、Draftを残して移動できる。
タブはセッション内だけで保持し、再起動やリロードでは復元しない。


## アプリ共通ショートカットの設定

ヘッダーの歯車、またはCmd/Ctrl + ,から「設定 → ショートカット」を開く。
保存、Quick Open、Quick Capture、タブ作成・現在のタブを閉じる、履歴移動、設定を開く操作を変更できる。
操作名・カテゴリで絞り込み、現在のキーを押してから新しいキーを入力する。Escで記録を取消し、Tabで次の項目へ移動する。
「解除」で未割り当て、「初期値」で操作単位の復元、「すべて初期化」で既定の割り当てに戻す。
同じ場面で競合するキーは登録できず、初期値への復元も他の割り当てと競合すると中止する。

設定はVaultとは別の端末ローカル保存で、WebとDesktopではそれぞれ保持する。
本文編集・検索・コピー等のキーは今回の変更対象外で、共通操作への割り当てを禁止する。
OS・ブラウザーの予約キーは取得できない場合があり、画面上のボタンも利用できる。
履歴移動は入力欄の外でのみ有効。モーダル中・IME変換中・キーの押し続けでは共通操作を起動しない。
追加のコマンドと実装の接続方法は[UIコマンド](ui-commands.md)を参照する。
