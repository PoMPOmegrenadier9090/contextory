# エディタのObject作成と行の見た目を直す

記録日: 2026-11-14

ユーザーが試して挙げた、Objectの作り方と行の見た目の問題を直した。前回の修正（行のそろえ方、タグの選択・削除など）は、うまくいかずに取り消している。今回は、その差分も参考にしながら作り直した。

## Objectの作り方

- **文に続けて`#`を打てる**：「資料を作る#task」のように、空白を挟まなくてもメニューが出る（Tanaと同じ）。`@`は、メールアドレスなどで誤って開かないよう、これまでどおり空白の後だけにしている。
- **作った後のカーソル**：Titleが入っていれば、Objectを開いて本文の空の行に入る。Titleが空なら、Titleに入る。本文を持ってObjectになった場合（見出し、リスト項目、選んだ範囲）は、Titleの末尾に置く。Title末尾の空白は除く。
- **見出し**：次の同じ階層か上の階層の見出しまでを本文にして、Objectにする。
- **リスト項目**：項目の行がTitleになり、入れ子のリストなど項目の残りが本文になる。Objectはリストの中に残り、項目の点の位置に種別のアイコンかチェックボックスが出る。リスト項目の先頭にObjectを置けるよう、`listItem`の内容を`(paragraph | objectBlock) block*`に広げた。Objectのリスト項目のTitleでEnterを押すと、次の項目ができる。
- **選んだ範囲**：複数の行を選んで`#`を打つと、選択を消さずに最初の行の末尾へ`#`を入れる。種別を選ぶと、残りの行を本文にする。範囲は最初の行から離れると忘れる。

範囲の決め方は`object-conversion.ts`に分け、単体テストを付けた。

## 行の見た目

- 行頭は、どの種別も同じ幅の欄に、種別の色の角丸アイコン（押すとObjectを開く）か、チェックボックスを置く。これでTaskの本文が、ほかのObjectと同じ位置にそろう。どの案にするかはユーザーと決めた。
- チェックボックスのある種別は、行にマウスを乗せると行末に「↗」が出て、そこから開く。
- 開閉ボタンは左の余白に浮かせ、行にマウスを乗せた時とキーボードで選んだ時だけ見せる。行の幅は取らない。
- Cmd+↓でカーソルのあるObjectを開き、Cmd+↑で畳む。畳む時はカーソルをTitleの末尾へ移す。Objectの外では、ブラウザーの既定の動きのまま。

## 確かめたこと

ブラウザーの別ポートのテスト用サーバーで、次を操作して確かめた。

- 文に続けた`#`
- 作った後のカーソル位置
- 見出しとリスト項目の変換
- 3行を選んだ`#`
- Cmd+↑・↓
- リスト項目のTitleでのEnter

あわせて、保存した文書の構造も確かめた。

日本語入力（変換中の`#`、全角の「＃」）は自動操作では確かめられないので、ユーザーに確認を頼む。全角の「＃」ではメニューは出ない。

## 残したこと

- 複数の行を選んで`#`を打つと、範囲の各行ではなく、範囲全体が一つのObjectになる。Tanaの、選んだ各ノードにタグを付ける動きとは違う。
- 取り消し（Cmd+Z）で変換を戻すと、`#`のメニューがまた開く。Tiptapのメニュー部品の動きのままにしている。
