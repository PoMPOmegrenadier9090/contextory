## 3. この期間に入れたもの

### View（PR #1）

- 種別ごとにViewを持つ。表とTimelineがあり、絞り込み、複数のキーでの並べ替え、配下の階層表示、畳んだ行を持てる。
- 表の追加行で`#種別 Title`と打てば、ほかの種別のObjectも作れる。`#`の後ろで種別を補う。
- 前回開いたViewと畳んだ行は、DB（`ui_state`）に置き、端末をまたいで同じ状態で開く（#3で`localStorage`から移した）。

### ゴミ箱とバックアップ（PR #2）

- 消すのは、ゴミ箱を通した操作だけである。ゴミ箱の画面で、戻す・完全に削除・空にするを行う。自動では空にしない。
- 文書の保存で外れ、ほかのどこにも置かれていないObjectは、ゴミ箱へ移る（#3で変えた）。取り消しや、別の文書への貼り付けで戻ると、保存がゴミ箱から戻す。作成日時とContextは残る。
- ユーザーが作った種別を消せる。その種別のObject（ゴミ箱の分を含む）や、継承している種別が残っていれば断る。
- サーバーは、起動時と1日1回`backups/`にDBを複製し、新しい7個を残す。`GET /api/next/backup`とMarkdownのzip（`GET /api/next/export/markdown`）を、設定の窓から落とせる。Macアプリは、メニュー「Contextory」から書き出す。

### 画面の作り直し（PR #3）

- 左のメニューは、上の帯の☰で開閉する。iPhoneでは本文の上に重ね、移ると閉じる。保存先とバックアップは「設定」の窓へ移した。
- 説明文を消し、上の帯を44pxにした。iPhoneでの拡大を止め、広い表でページが横に伸びないようにした。
- 埋め込んだObjectは、Escでブロックごと選べる。⌫でゴミ箱へ移し、⌘X・⌘Cで切り取りとコピーができる。
- 埋め込んだObjectの「⋯」と右クリックで、開く・切り取る・コピー・種別を変える・Objectを解除・削除・新しいObjectを埋め込む、を選べる。文字を選んでいれば、書式も選べる。
- 表の行の「⋯」から、種別を変える・ゴミ箱へ移す、を選べる（`ObjectPatch`の`type`）。
- Timelineは、日付の見出しの下に、本文の先頭を読めるカードで並ぶ。
- iPhoneでは、キーボードの上に書式の帯（太字、斜体、取り消し線、インデント、＋、キーボードを閉じる）を出す。
- 保存のたびに、埋め込んだObjectがすべて描き直されていた。中身が変わらなければ描き直さないようにし、開閉の遅れを減らした。

## 4. 決まっている方針

- 黙って完全に消す処理は作らない。消したものは、必ずゴミ箱から戻せる。
- 初回リリースでは、オフラインでの編集を扱わない。扱うときは、端末間の競合をどう解くかを先に設計する。
- 大きな作業は、実装の前に変更の計画を`docs/discussions/`に書き、確認を取る。小さな修正は、そのまま進める。
- 途中経過の文書は`docs/discussions/`に`yyyymmdd_`を付けて置く。日本語の文書とPRの説明は、natural-japaneseのskillで整える。
- Timelineのカードは本文の先頭だけを出し、カードの中では書かない。

## 5. 作業の進め方

### 試すためのサーバー

利用中のデータを書き換えないよう、作業用のフォルダを使う。起動の設定は`.claude/launch.json`（Gitの管理対象外）にある。

| 名前               | port | データ                                | 使い方                                                           |
| ------------------ | ---- | ------------------------------------- | ---------------------------------------------------------------- |
| `view-test-server` | 5196 | セッションの作業フォルダの`view-data` | ユーザーも同時に触る。こちらから本文へ文字を打たない             |
| `ui-test-server`   | 5195 | 同じく`ui-data`（5196のデータの複製） | 作業者が操作を試す用                                             |
| `phase3-server`    | 5197 | 以前のセッションの作業フォルダ        | ユーザーの試用中のデータ。触らない。再起動するとスキーマが上がる |

- 作業フォルダはセッションごとのscratchpadにあり、消えることがある。新しく作るときは、`PKM_SERVER_DATA_DIR`に空のフォルダを渡す。
- iPhoneから試すときは、同じWi-Fiで`PKM_SERVER_HOST=0.0.0.0`を付けて起動し、Macのアドレス（`ipconfig getifaddr en0`）を開く。認証が無いので、試し終えたら止める。
- ブラウザーは、Service Workerが古い版を返すことがある。ビルドし直したら、Service Workerを外し、キャッシュを消してから読み直す。

### 検証

- `corepack pnpm check`（format、型、lint、テスト）と`corepack pnpm build`
- `corepack pnpm --filter @pkm/desktop smoke:electron`。終わったら`corepack pnpm rebuild better-sqlite3`でNode用に戻す。
- 画面の変更は、試すためのサーバーで実際に操作して確かめる。ユーザーが同じ画面を使っていることがあるので、文字を打つ前に入力欄へフォーカスを移し、値を確かめる。

## 6. 残っている作業

### 先に確かめること

- iPhoneの実機で、キーボードの上の帯（中央寄せ、スクロール中に隠す、候補と重ならない）、拡大の停止、埋め込みの開閉の速さを見る。
- 右クリックからの切り取りとコピー（`document.execCommand`）を、Safari・Chrome・Electronで試す。
- Macアプリのメニュー「バックアップを書き出す…」「Markdownで書き出す…」を実際に使う。
- `docs/server-setup.md`の、Dockerでバックアップから戻す手順を試す。
- インストール済みのContextory.appを、バックアップを取ってから置き換える。

### 次の改善

1. **ブロックの選択を使いやすくする**（ユーザーが後回しにした）。Shift＋矢印やドラッグで複数のブロックを選ぶ、iPhoneでつかみやすくする、など。
2. **検索の画面**。今は`@`の候補でしか探せない。
3. **日付と選択のFieldを、キーボードで操作する**。Dailyの日付の窓に「日付なし」を足す。
4. **Viewを文書に挿入する**（右クリックのメニューの「将来」の項目）。
5. 埋め込みのContext：今は、置いた文書と違うContextだけを小さな文字で出す。開いたときのContextの行（チップ）の見せ方は、まだ変えていない。

### 知っている問題

- キーボードの上の帯は、`requestAnimationFrame`で位置を決める。作業用のブラウザーではページが隠れた扱いになり、出るのが遅れることがある。実機では起きない見込みである。
- コピーして貼ったObjectは、新しいIDを振らない。同じObjectが二つの文書に置かれ、どちらで書いても同じObjectが変わる。
- 種別を変えると、新しい種別に無いFieldの値は消える。戻しても値は戻らない。
